Gobble Dash — a turkey escapes becoming Thanksgiving dinner. Outrun the
farmer across the farmyard, the barn and the kitchen: jump fences, hide in
haystacks, dodge the oven and the carving knives, and reach the far gate
before you are caught.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Then serve the game folder with any static server and open it in a browser:

```sh
cd game && python3 -m http.server 8080
```

Controls: arrow keys or WASD to run and jump, down to duck and hide,
Shift to dash, mouse click to jump, hold the mouse button to dash.
Enter starts and restarts.
